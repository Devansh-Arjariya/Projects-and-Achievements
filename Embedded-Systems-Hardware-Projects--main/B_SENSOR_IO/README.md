# 🌐 Sub-Division: Sensor Telemetry & IoT Systems

> **Environmental atmospheric chambers, industrial wearable monitors, patented healthcare dispensers, and biomimetic solar harvesters.**

---

## 🎯 Overview

The **Sensor & IoT** sub-division bridges real-world physical and chemical phenomena—temperature, relative humidity, volatile organic gases, weight variations, sunlight incidence, and biometric identity—with microcontrollers and cloud endpoints.

The projects housed in this category tackle mission-critical societal challenges across **Agriculture**, **Occupational Safety**, **Healthcare**, and **Renewable Energy**.
